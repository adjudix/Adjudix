# ICCA / arbitration-icca.org (Institutes Directory) — Competitor Analysis

Source: https://www.arbitration-icca.org/ and https://www.arbitration-icca.org/institutes (fetched Sept 2026)

## Overview
ICCA (International Council for Commercial Arbitration) is a UN-accredited worldwide NGO — not a case-administering institution but a knowledge/community/publications body for the arbitration field as a whole (congresses, yearbooks, judicial outreach, a global institutes directory). Its relevance to Adjudix is narrow but specific: (1) it models what a "knowledge centre" and "directory of institutions" look like at the field-wide level, and (2) being *listed* in ICCA's institutes directory is itself a credibility milestone Adjudix should pursue once operational.

## Primary Purpose
Promote and improve the practice of arbitration/ADR globally through publications, congresses, judicial education (New York Convention outreach), and a reference directory of arbitral institutions worldwide.

## Navigation Structure
- **Congresses** (upcoming/past events — e.g., 2028 San Francisco Congress)
- **Publications** (Yearbook, Handbook, Awards Series, a searchable historical-awards database for African-government arbitrations)
- **Judicial Outreach** (New York Convention Roadshow — judicial education colloquia since 2012)
- **Projects** (working groups, fellowship programs)
- **About ICCA** (governance)
- **Membership**
- **Diversity & Inclusion** (dedicated standalone nav item — notable as a first-class nav item, not buried in About)

## Component Inventory
- **Country-filterable institute directory**: dropdown of countries (alphabetical) + free-text search by "name or address," results in a **table** (Country / Institute Name / Address / Telephone / Email / Website), paginated (9+ pages). This is a reference/utility component, not a marketing one — plain, functional, data-dense.
- **Congress/event promo module** for a single flagship recurring event (the Congress), similar in spirit to MCIA's India ADR Week and CIArb's Alexander Lecture — recurring flagship events are a consistent pattern across every institution studied so far.
- **Searchable historical-award database** — a specialized knowledge-center search tool scoped to one dataset (African-government arbitral awards), showing that a knowledge centre doesn't have to cover everything at once; a narrow, well-curated searchable dataset is more valuable than a shallow broad one.
- **Standalone Diversity & Inclusion nav item** — worth noting as a deliberate top-level IA choice by a leading field body, signaling this is treated as core positioning, not a footer afterthought.

## Homepage Breakdown
Lead: mission statement (NGO, UN-accredited) → upcoming Congress promo → publications/knowledge highlights → judicial-outreach program feature → recent news (membership restructuring, UNCITRAL collaboration). Skews toward institutional/field-level authority messaging rather than user-journey CTAs (no "file a case," no "join now" button structure visible — consistent with ICCA not being a service provider).

## Training Components
None in the arbitration-institute sense — ICCA's "training" equivalent is its **Judicial Outreach** program (judge education) and **Fellowships** (career-development for the field), not commercial courses/certifications. Not a direct model for Adjudix's Training Institute.

## Membership Components
ICCA membership is field-wide/individual-practitioner and organizational (institutes can be listed/registered), oriented toward participation in the field's discourse (congresses, publications access) rather than a credentialing ladder like CIArb's. Not a strong model for Adjudix's membership-tier design, but validates that **a directory listing of institutions is itself a "membership" artifact worth having** (see below).

## Arbitration Components
None — ICCA does not administer arbitrations or publish its own procedural rules for case use.

## ODR Components
None found.

## Design Language
**Confirmed via live browser screenshots (Sept 2026 update).** ICCA's identity is built on a **deep navy-blue diagonal-gradient hero** (navy fading to near-black, with faint diagonal line texture) paired with a genuine **serif display typeface** for headlines ("International Council for Commercial Arbitration") — the only site in the entire competitor set to use a scholarly/editorial serif rather than a sans-serif for its primary headline type. This immediately signals "academic/publications authority" rather than "corporate service brand," consistent with ICCA's actual role as a knowledge/NGO body rather than a case-administering institution. An **amber/orange accent** (used for the "Become a member" pill button and news-date highlights) is the sole warm counterpoint against the cool navy field — a clean two-color system. A small pill-shaped toggle ("ICCA / Young ICCA") sits above the main nav, mirroring the "main body + young-professionals arm" pattern seen at MCIA (Young MCIA) and SIAC (YSIAC). Below the fold, content reverts to plain white-background, text-and-table-dense layout (news list, congress promo block) — the visual sophistication is concentrated entirely in the hero/brand layer, with utilitarian, document-oriented layout underneath. Overall: authority-through-scholarship positioning (serif type, navy/amber restraint) rather than authority-through-service-polish (which is more SIAC/CIArb's register).

## Strengths
- The Institutes Directory is a genuinely useful, well-structured reference tool (country filter + name/address search + clean tabular data) — good model for **any** directory Adjudix needs to build (e.g., a public directory of its own panel members, or a partner/education-partner directory)
- Diversity & Inclusion as a first-class nav item shows how a leading body signals values at the IA level, not just in a paragraph of text
- Narrow, well-curated searchable datasets (the African-awards database) outperform trying to be an exhaustive knowledge base at launch

## Weaknesses
- No service-oriented CTAs or user journeys — appropriate for ICCA's mission but not a model to copy wholesale for Adjudix, which does need "file a case" / "join now" / "book training" journeys
- Directory is contact-info only (no institute profile pages, no logos, no descriptions) — a missed opportunity; being listed conveys less credibility than it could

## Elements Worth Reusing (for Adjudix)
- Country/category-filterable, searchable table pattern — directly reusable for Adjudix's own "Our Professional Panel" directory (filter by dispute-type specialization, jurisdiction, membership grade) and for an "Education/Training Partners" directory
- Standalone top-level nav item for a values-based commitment (Diversity & Inclusion) — Adjudix could consider similar treatment for something like "Ethics & Neutrality" or "Access to Justice," reinforcing the "Moral Code of Principles" mentioned in its own project notes
- Scoped, narrow, well-curated knowledge datasets rather than an unfocused blog — supports Adjudix's "Blogs & Articles" / "Research & Publications" module: better to build a few excellent, structured resources (e.g., a searchable clause library, a searchable case-summary index) than a generic unstructured blog feed

## Elements Worth Improving (things Adjudix should do better)
- If Adjudix builds a public panel/partner directory, give each entry a real profile page (photo, bio, specialization, credentials) rather than ICCA's contact-info-only row — this matches Adjudix's own "Our Professional Panel" and "Our Esteemed Members" pages which imply richer profiles
- Since ICCA has no service journeys, Adjudix must not copy its passive, document-first tone for its own service pages (Arbitration/ODR/Training/Membership) — those need clear CTAs, forms, and conversion paths that ICCA's field-body model doesn't require
- Once live, Adjudix should actively pursue listing in ICCA's Institutes Directory as an early credibility/backlink milestone (add to the launch/marketing checklist, not a design requirement)
