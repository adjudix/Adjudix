# Japanese (ja) glossary — Adjudix

Register: prose in formal です・ます; UI labels in concise noun style; Code provisions (Articles, Rules) in である style of Japanese rules.
Punctuation: 、。「」『』（）・ ; full-width parentheses around Japanese glosses. Names, emails, URLs, codes stay in Latin script.
Statutes: English title kept, first time in a string followed by a gloss, e.g. "Arbitration and Conciliation Act, 1996（1996年仲裁調停法）" — the year inside the gloss is only written if it is part of the key text itself (never write numbers that are {n} slots).
